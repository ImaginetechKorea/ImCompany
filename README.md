# ImCompany

Windows PC에서 수주, 발주, 청구, 입금과 지급을 관리하는 프로그램입니다.

## 다운로드와 실행

Windows 64비트 PC에서 다음 순서로 실행하세요. 별도의 .NET 설치는 필요하지 않습니다.

1. [Windows 다운로드 페이지](https://github.com/ImaginetechKorea/ImCompany/releases/latest)에서 **ImCompany-Windows-x64.zip**을 내려받습니다. GitHub의 Source code 파일이 아닌 Windows용 ZIP을 선택하세요.
2. 다운로드한 ZIP 파일을 마우스 오른쪽 버튼으로 클릭하고 **모두 압축 풀기**를 선택합니다. 예를 들어 문서 폴더 아래의 **문서\ImCompany** 또는 **C:\ImCompany**에 풀면 됩니다. 원하는 다른 폴더를 사용해도 됩니다.
3. 압축이 풀린 폴더를 열어 **ImCompany.exe**를 두 번 클릭합니다. 압축파일 안에서 직접 실행하지 말고 압축을 먼저 풀어 주세요. 실행 파일과 함께 풀린 다른 파일과 폴더도 그대로 두어야 합니다.
4. 웹브라우저가 자동으로 열리면 프로그램을 사용하세요. 자동으로 열리지 않으면 Edge, Chrome 등 브라우저의 주소창에 **http://127.0.0.1:5274/** 를 입력하고 Enter를 누릅니다. 이 주소는 프로그램을 실행한 PC 자신의 주소입니다.
5. 처음 실행하면 설정에서 회사 정보를 입력합니다. 브라우저 창을 닫아도 프로그램은 계속 실행되며, 완전히 종료하려면 프로그램의 **설정 → 프로그램 종료**를 선택합니다.

## 주요 기능

- 거래처, 프로젝트별 수주·발주, 청구·입금·지급과 잔금 관리
- 발주서 인쇄 및 PDF 저장, 납품·입고·매입 기록
- 세금계산서와 문서 이미지·PDF를 이용한 AI 입력안 검토 및 저장
- 첨부 원본과 복원 정보를 포함한 엑셀 백업

## 프로젝트와 자산 관리

- 프로젝트 현황에서 수주 등록일자와 연결된 발주·청구·입금·작업을 펼쳐 확인합니다.
- 자산 관리에서 장비·비품, 구입 정보와 증빙을 기록하고 정액법·정률법의 월별 추정 상각액을 확인합니다.
- 즉시상각 검토를 선택한 자산은 사업 사용 시작일의 귀속연도별로 세무사 전달용 엑셀 목록을 만듭니다. 신고 확정 자료가 아니며 증빙 원본은 별도로 전달해야 합니다.
- 총 결제금액에서 10% 과세 상품의 공급가액·부가세를 계산할 수 있습니다. 증빙과 공제 여부를 확인하고 취득금액과 즉시상각 검토금액을 직접 지정합니다. 세무상 적용 조건과 금액은 세무사와 확인하세요.

## 자료 저장과 AI 연결

업무자료는 각 PC의 `%LOCALAPPDATA%\ImCompany\ImCompany` 폴더에 저장되며 처음 실행할 때는 비어 있습니다. 설정에서 엑셀 백업을 만들어 다른 저장장치에 보관하세요. 백업에는 업무자료와 첨부 원본이 포함됩니다.

AI는 ChatGPT 로그인(Codex) 또는 호환 API 연결을 설정한 경우 사용할 수 있습니다. AI에 보내기를 누르면 첨부 자료와 입력한 내용이 선택한 AI 서비스로 전송됩니다. AI가 제안한 내용은 확인 후 저장하세요. 프로그램은 은행 이체나 전자세금계산서 발급을 실행하지 않습니다.

## 소스에서 빌드

.NET SDK 10.0.401이 필요합니다. `dotnet restore` 후 `dotnet build --no-restore`로 빌드하거나 `Publish-ImCompany.ps1`로 Windows 배포본을 만들 수 있습니다.
